# がるちゃんアプリ

がるちゃんをより快適に使える macOS アプリケーションです。

## 📱 このアプリについて

- **対応OS**: macOS 10.11 以上
- **対応Mac**: Intel Mac、Apple Silicon Mac（M1/M2 など）全対応
- **サイズ**: 約 44MB

## 🚀 インストール

詳しくは **INSTALL.md** を参照してください。

基本的な手順：
1. Google Drive から `girlschan_app.dmg` をダウンロード
2. DMG ファイルをダブルクリック
3. `がるちゃんアプリ` を Applications フォルダにドラッグ
4. 起動したら完了！

## 📋 システム要件

- **Mac（macOS 10.11 以上）**
- **メモリ：2GB 以上**
- **空き容量：100MB 以上**

## ⚠️ 初回起動時について

セキュリティ機能によるメッセージが表示される場合があります。
INSTALL.md の「初回起動時に『ファイルが破損している可能性があります』と表示される場合」を参照してください。

**A:** はい、完全無料です。
